# Code Review Skill

## Workflow

1. Read the changed files
2. Check for common issues
3. Run format and lint checks
4. Summarize risks and improvements

## Rules

- Focus on correctness, not style nitpicks.
- Call out security-sensitive changes.
- Always verify before approving.
