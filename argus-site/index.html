Features

Everything you need to manage Minecraft, nothing you do not.

Minecraft Instances

Manage multiple Minecraft instances from one launcher. Create, configure, and launch separate game setups with custom memory, resolution, and Java versions.

Java Provisioning

ARGUS automatically detects installed Java and downloads managed runtimes when needed. No manual JDK setup required — Java is provisioned on first launch and reused forever.

Modrinth

Discover and install mods, resource packs, shaders, and full Modrinth modpacks. Packs are provisioned automatically — every indexed file is fetched with SHA-1 verification and overrides are applied to your instance.

Terminal UI (TUI)

A keyboard-driven terminal interface built with Ratatui. Fast, efficient, and distraction-free. Perfect for power users and headless servers.

Lightweight

Windows release is approximately 13.6 MB. No bloat, no telemetry, just the launcher. Runs entirely locally on your machine.

How it works

01

Download ARGUS

Grab the Windows executable from the latest GitHub release.

02

Create or launch an instance

Set up a new Minecraft instance or launch an existing one. Java is auto-detected or downloaded.

03

Play Minecraft

Jump in. ARGUS handles Java, mods, and instance management.
